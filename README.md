# Domain Landing Page

Temporary landing page for **sidakpreetsingh.com** while the full portfolio is under development.

## Purpose

This repository hosts the public-facing landing page for my personal domain. It serves as a lightweight placeholder containing:

* Personal identity and branding
* Contact information
* Links to professional profiles
* Project status updates
* Domain ownership verification

The long-term goal is to replace this landing page with a full portfolio website.

## Tech Stack

* HTML
* CSS (embedded)
* Vanilla JavaScript
* DNS managed through Cloudflare
* Domain registered through Porkbun


## Deployment

Deployment is automated through Vercel.

```text
GitHub
  ↓
Vercel
  ↓
sidakpreetsingh.com
```

Every push to the main branch triggers a new deployment.
